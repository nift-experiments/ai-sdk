Run python3 benchmark-campaign.py LABEL in an otherwise idle environment. LABEL creates resumable external logs/samples/snapshots; do not reuse a label for changed source/toolchain. The separate upstream-changed.py temporarily edits an isolated local clone with immutable input backups, performs one production publication per controlled case and restores all inputs; never point AI_SDK_UPSTREAM_CHANGED_CHECKOUT at a maintained checkout. Read scripts and available disk requirements before reproduction.

The failed and interrupted setup attempts are retained separately with zero accepted samples.

Place the isolated changed-input checkout on the same filesystem as the measured projects.
