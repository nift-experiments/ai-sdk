# A3 scope and acceptance

Seven representative routes: home; current/v6/v5 introduction; streamText reference; OpenAI provider; Next.js generate-text cookbook. All six document bodies match the frozen reference for normalized text, heading anchors, link text/href pairs and exact code text. React-generated IDs differ because islands have independent roots; their ARIA relationships stay scoped and functional.

Browser actions passed on both source models: provider-tab code changes, real hero capability/model-source changes, simulated generation, and independent hydration without console warnings/errors in the exercised states. Theme is a shared static control with vanilla behavior. Only one representative bundle observation is recorded; no performance winner is claimed.

Each source model passed changed-page/literal-template, island-source/client+SSR, metadata title+description removal, and shared-theme incremental vs forced publication checks. Corrupt/missing rendered caches recover from maintained inputs. Tests restore inputs and retire obsolete owned island artifacts. The corpus, complete shared-shell interactions, search, projections, OG/query/runtime routes, deployment, final browser parity, headline benchmarks and clean-checkout acceptance remain open.

The six document shell fragments are seeded from frozen reference HTML for the architecture proof. Their title/description fields are now derived from authoritative frontmatter (authored model) or explicit metadata (rendered model). Full navigation/version/route ownership is required before broad acceptance; these seed fragments are not an assertion that a frozen per-page shell is the final maintenance architecture.

Reference captures used requested desktop 1440×1000 and mobile 390×844 CSS viewports. The screenshot tool emitted JPEG bytes under .png filenames with 1425×990 / 375×812 image extents. Snapshot hashes preserve those bytes; A7 must record actual CSS dimensions and image extents for each compared state. Early prototype captures used the new tab's default viewport and are interaction evidence, not matched pixel-parity claims.
